                                                  # Simple-Linear-Regression-Task-3
 ## project Title:
 Simple Linear Regression using Salary Dataset

## Project Overview:
This project demonstrates how to build a Simple Linear Regression model using the Salary Dataset. The model predicts an employee's salary based on their years of experience using Scikit-learn.

## Objective:
- Load the Salary Dataset.
- Train a Simple Linear Regression model.
- Predict salary based on years of experience.
- Evaluate the model using performance metrics.
- Visualize the regression line.

## Dataset:
- Dataset Name: Salary_Data.csv
- Features:
  - YearsExperience (Independent Variable)
  - Salary (Dependent Variable)

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Steps
1. Import required libraries.
2. Load the dataset.
3. Explore the dataset.
4. Check for missing values.
5. Select features and target.
6. Split the dataset into training and testing sets.
7. Train the Simple Linear Regression model.
8. Predict the test data.
9. Evaluate the model using MAE, MSE, and R² Score.
10. Visualize the regression line.
11. Predict salary for a new experience value.
12. Save the trained model.
# Set Up Instructions

- Python 3.10 
- Google Colab or Jupyter Notebook

## Steps to Run the Project

1. Download or clone the project.
2. Place `Salary_Data.csv` in the project folder.
3. Open the notebook in Google Colab or Jupyter Notebook.
4. Run all cells from top to bottom.
5. The model will:
   - Load the dataset
   - Train the Simple Linear Regression model
   - Evaluate the model
   - Display the regression graph
   - Predict salary for a given years of experience


## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## Output
The model predicts salary based on years of experience and displays a regression line showing the relationship between the variables.
